# asmb-buvette
Caisse buvette General Manager — reliée en temps réel à l'inventaire et à la
comptabilité du club (repo `ecole-app/asmb-basket`).

Aucun compte : un dirigeant ou membre du bureau génère un code court (valable
jusqu'à la fin de la journée) depuis General Manager (Inventaire → Buvette →
🔑 Accès caisse) et le transmet au bénévole tenant la caisse. Le code ouvre la
caisse pour son club ; chaque vente décrémente le stock et crée la ligne
comptable correspondante automatiquement.
